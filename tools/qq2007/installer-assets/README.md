# Codex QQ2007 皮肤（macOS）

适用于已经安装 Codex Dream Skin 的 macOS 用户。主题昵称已统一为“QQ用户”，安装包不含制作者的聊天记录、账号信息和本机路径。

1. 解压 ZIP。
2. 双击 `安装 QQ2007 皮肤.command`。
3. 安装完成后手动退出 Codex，再双击桌面的 `Codex QQ2007.command`。

安装器会先检查环境和包内文件，再备份并修改 Dream Skin 引擎。它不会强制退出或重启 Codex。重复安装不会重复追加皮肤补丁。

需要撤销扩展时，双击 `恢复原始皮肤.command`。恢复只还原安装器备份的引擎资源，不删除其他主题。
