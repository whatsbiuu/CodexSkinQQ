# Codex 2007 主题

QQ 2007 风格的 Codex Dream Skin 主题包。

- `theme.json`：主题元数据与配色。
- `background.jpg`：主题背景纹理。
- `qq2007-chrome.html`：不可交互的复古窗口装饰结构。
- `qq2007-extension.css`：任务栏、对话区、输入区和右侧好友栏样式。
- `profile-codex.png`：Codex 卜卜客服档案图。
- `profile-avatar.png`：好友栏成年虚拟人物图。
- `profile-penguin.png`：左下角企鹅头像。

人物和宠物素材为项目定制素材或由图像生成工具辅助创作，不包含 QQ 秀原图或腾讯
官方企鹅素材。

安装、恢复和兼容性说明见仓库根目录的 [`README.md`](../../README.md)。
